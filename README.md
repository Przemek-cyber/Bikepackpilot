# BikepackPilot

Offline planner for self-supported bikepacking trips — **https://bikepackpilot.com**

- Split your route into 50 km segments, set surface, heat, wind and rain for each.
- Get realistic riding days, a gear list that adapts to conditions, and water, food, repair and lodging nearby.
- Works offline, installs like an app, in English, Polish, German and Spanish.
